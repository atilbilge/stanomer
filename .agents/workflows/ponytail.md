# Workflow: ponytail

Follow the `ponytail` skill to apply the lazy senior developer decision ladder to the current task.

- **lite**: Suggest the minimal alternative, let the user pick.
- **full** (default): Enforce the decision ladder, shortest diff, zero bloat.
- **ultra**: Aggressive YAGNI, delete before add, one-liners wherever possible.
